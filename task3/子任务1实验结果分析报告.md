## 三、核心发现

### 发现 1: Transformer 的外推能力为零

| 实验 | 训练 | 测试 | 结果 |
|------|------|------|------|
| extrapolate_4plus4 | 3+3 | 4+4 | 0.000 |
| extrapolate_5plus5 | 3+3 | 5+5 | 0.000 |

即使模型在 3+3 上达到了 100% 验证准确率，换到 4+4 后准确率直接降为 0%。

**原因分析：**
- 位置编码（sin/cos）的最大值 `max_len=20`，4+4 序列长度为 10，理论上还在范围内
- 但进位逻辑在更长序列上需要更多步推理（进位传播链更长）
- Attention 模式是针对 3 位数学到的，无法泛化到 4 位数
- Decoder 在推理时需要处理从未见过的序列长度组合

**结论：** 纯同分布训练完全无法外推到更长序列。这是 Transformer 的已知弱点。

### 发现 2: 混合训练是外推的唯一解法

| 实验 | 训练 | 测试 | 结果 |
|------|------|------|------|
| baseline_3plus3 | 3+3 | 3+3 | 0.989 |
| extrapolate_4plus4 | 3+3 | 4+4 | **0.000** |
| mixed_test_4plus4 | 2+2~5+5 | 4+4 | **0.927** |

混合训练后，4+4 测试准确率从 0% 跳到 92.7%。证明"见过多种长度"是外推的前提。

**但混合训练有缺点：**
- 总体准确率下降：3+3 从 98.9% 降到 91.95%（混合了简单和困难任务）
- 训练数据分布不均衡：5+5 只有 1000 条，比 3+3 的 3000 条少很多

### 发现 3: 课程学习是最优训练策略

| 实验 | 训练方式 | Val Acc | Test Acc |
|------|---------|---------|----------|
| mixed_training | 随机混合所有长度 | 0.955 | 0.9195 |
| **curriculum_learning** | 先 2+2 → 3+3 → 4+4 → 5+5 | **0.995** | **0.982** |

课程学习比直接混合训练提升了 **6.25 个百分点**。

**课程设计：**
```
Epoch  1-15: 只学 2+2（最简单的加法）
Epoch 16-30: 学 2+2 + 3+3
Epoch 31-40: 学 2+2 + 3+3 + 4+4
Epoch 41-50: 学 2+2 + 3+3 + 4+4 + 5+5
```

**为什么有效：**
- 先学简单的，让模型建立基本的加法概念
- 逐步增加难度，模型有时间适应更复杂的进位逻辑
- 最终阶段学习 5+5 时，模型已经具备了处理 4 位数的能力

### 发现 4: 深度比宽度重要

| 实验 | 层数 | 维度 | 参数量 | Test Acc |
|------|------|------|--------|----------|
| baseline | 2 | 128 | ~0.3M | 0.989 |
| **deeper_4layers** | **4** | 128 | ~0.6M | **1.000** |
| wider_256d | 2 | 256 | ~1.0M | 0.989 |

**4 层模型在同分布上达到了 100% 准确率，而 2 层 256d 模型只有 98.9%。**

原因分析：
- 进位逻辑是多步推理：每一位的计算依赖前一位是否进位
- 更深的网络可以逐层学习"检测进位 → 处理进位 → 传播进位"的推理链
- 加宽只是增加了表达能力，但没有增加推理深度

### 发现 5: RoPE 和 Warmup 都有帮助

| 实验 | 位置编码 | 学习率 | Test Acc |
|------|---------|--------|----------|
| baseline | sin/cos | 固定 | 0.989 |
| rope_enc_dec | RoPE | 固定 | 0.995 |
| warmup_scheduler | sin/cos | Warmup | 0.995 |

两种改进都带来了 consistent 的提升（+0.6%），但提升幅度相同。

**RoPE 为什么有效：**
- RoPE 在注意力计算时对 Q/K 应用旋转，编码了相对位置关系
- 相比 sin/cos 的绝对位置编码，RoPE 的位置表示更灵活

**Warmup 为什么有效：**
- 前期用小学习率，让模型先建立基本的注意力模式
- 后期学习率自动衰减，避免震荡

### 发现 6: Decoder-only 不如 Enc-Dec

| 模型 | Test Acc |
|------|----------|
| Enc-Dec | 0.989 |
| Dec-Only | 0.955 |

Enc-Dec 架构在 seq2seq 任务上天然更合适：
- Encoder 专注理解问题（"123+456="），输出上下文表示
- Decoder 专注生成答案（"579"），利用 Encoder 的表示做推理
- Decoder-only 要同时做两件事：理解问题 + 生成答案

## 四、实验结论总结

| 维度 | 最佳选择 | 证据 |
|------|---------|------|
| 模型架构 | Encoder-Decoder | Enc-Dec > Dec-Only（0.989 vs 0.955） |
| 模型深度 | 4 层 | deeper_4layers 达到 100% |
| 位置编码 | RoPE / sin/cos + warmup 都行 | 都是 0.995 |
| 同分布训练 | 4 层 + warmup | 达到 100% |
| 外推训练 | 课程学习 | 0.982，远超混合训练 0.9195 |
| 外推结论 | 纯同分布训练无法外推 | 3+3→4+4 = 0% |

## 五、关键公式回顾

### Multi-Head Attention

```
Attention(Q, K, V) = softmax(QK^T / sqrt(d_k)) * V

Q = X * W_Q
K = X * W_K
V = X * W_V
Output = concat(head_1, ..., head_h) * W_O
```

### Scaled Dot-Product 的意义

```
scores = Q @ K.transpose(-2, -1) / math.sqrt(self.d_k)
```

除以 `sqrt(d_k)` 的原因：当 `d_k` 很大时，`Q·K` 的点积方差约为 `d_k`，会导致 softmax 进入饱和区（梯度极小）。除以 `sqrt(d_k)` 把方差归一化到 1。

### RoPE 旋转位置编码

```
# 对 Q 和 K 的每对相邻维度应用旋转
x_rot = [-x_2, x_1]  # 旋转 90 度
Q = Q * cos(pos * freq) + rotate_half(Q) * sin(pos * freq)
```

### Warmup 学习率调度

```
lr = d_model^(-0.5) * min(step^(-0.5), step * warmup_steps^(-1.5))
```

前 `warmup_steps` 步学习率线性上升，之后按 `step^(-0.5)` 衰减。
